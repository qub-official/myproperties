질문 · FAQ

Good questions

Is it safe? Does it send my data anywhere?

Everything runs locally. MyProperties has no accounts, analytics or network calls. The full source code is on GitHub for you to read.

Why does Windows SmartScreen warn me?

Code-signing certificates are expensive, so the builds are unsigned for now. Click “More info” and then “Run anyway”. You can also build the app yourself from source.

Do I need administrator rights?

No. A few protected system folders can't be read without admin rights; they're shown as “locked” and skipped. All theme changes are per-user.

Can it scan my phone?

Yes. Phones and cameras connected over USB (MTP) appear under sources. Unlock the phone and choose “File transfer”. Device scans are slower than disk scans.

Will a live wallpaper slow down my PC?

Scenes are lightweight canvas animations. Videos use hardware decoding. Playback pauses when you lock the PC and, if you like, when you run on battery.

How do I remove the live wallpaper?

Click “Stop” on the Live Wallpaper page or use the tray icon. Your normal wallpaper comes right back.
